# Notes — notas exploratorias de mejora

Carpeta exclusiva para guardar ideas de mejora que surgen al usar el
proyecto. Son notas vivas, no tareas del BACKLOG ni decisiones.

## Convención

- Un archivo por idea: `NNN-titulo-corto.md` (numeración secuencial).
- Cada nota: contexto donde surgió → problema observado → propuesta →
  estado (`idea` / `en discusión` / `aceptada→BACKLOG` / `descartada`).
- Las notas NO generan trabajo por sí solas. Si una idea se acepta, se
  convierte en tarea del BACKLOG por el flujo habitual.
- Prohibido: secretos, credenciales, tokens, IDs reales.
