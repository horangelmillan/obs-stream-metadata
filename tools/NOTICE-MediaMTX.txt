Local relay bundled with obs-stream-metadata: MediaMTX
============================================================

This product bundles the MediaMTX executable (mediamtx.exe) plus the
minimal configuration in this directory (mediamtx.yml), as a local
relay so the operator can always stream to one fixed URL
(rtmp://127.0.0.1:1935/live). See ADR-016 and tools/MEDIAMTX.md.

MediaMTX upstream: https://github.com/bluenviron/mediamtx
Pinned release used by the installer: v1.21.3
  asset: mediamtx_v1.21.3_windows_amd64.zip
  origin: https://github.com/bluenviron/mediamtx/releases/download/v1.21.3/
  sha256: b2f5246b07cb72961df03b8d5e8cad43dc657bcf3f49a87bb031bdf22721af74
  (verified at build time by tools/package.ps1 against the pinned hash
  and the release checksums.sha256; the binary is never versioned.)
